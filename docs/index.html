sqlhelperv4

uptrace/bun 的代理对象,用于解决 PostgreSQL、MySQL、SQL Server 与 SQLite 的连接、连接池与生命周期管理问题。驱动按需引入,核心模块不依赖任何具体数据库实现。

API 文档

  • bunproxy (v4, 当前版本) 核心包:Proxy、Options、驱动注册表等全部导出接口
  • bunproxy (v3, 旧版本) 内置全部驱动的上一代实现,新项目请使用 v4

驱动子模块

  • driver/all/v4 一次性引入全部后端(同一个二进制支持多后端、停机切换配置)
  • driver/postgres/v4 启用 postgres:// 连接串
  • driver/mysql/v4 启用 mysql:// 连接串
  • driver/sqlserver/v4 启用 sqlserver:// 连接串
  • driver/sqlite/v4 启用 sqlite:// 连接串

使用文档

  • README 安装、快速开始、支持的数据库、配置项、回调、超时、日志与安全
  • 从 v3 迁移到 v4 驱动 import 对照表、命名调整与新能力说明
  • 从 v2 迁移到 v3 历史迁移说明
  • CHANGELOG 各版本的接口变更、bug 修复与行为调整记录
